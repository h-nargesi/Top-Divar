# Top Divar

پایش خودکار سایت دیوار برای پیدا کردن آگهی‌های خوب و اطلاع‌رسانی فوری از طریق تلگرام.

> این repo برای همیشه خصوصی می‌ماند — دادهٔ شخصی در `config.yaml`/`docs/fetch-sample.md` مجاز است (نمونه‌های خام با نشان `REDACTED` اسکراب می‌شوند)؛ repo عمومی ساخته نمی‌شود (تصمیم ۲۰۲۶-۰۹-۱۸).

## وضعیت

🚧 طراحی قفل شده؛ پیاده‌سازی مرحله‌ای — ترتیب کار در [مراحل پیاده‌سازی](docs/implementation.md). هنوز کدی نوشته نشده است.

## هدف

کاربر فیلترها و معیارهای خود را تعریف می‌کند (مثلاً دسته‌بندی، محدوده قیمت، شهر)؛ سیستم به‌صورت دوره‌ای دیوار را بررسی می‌کند و هر آگهیِ منطبق و «به‌صرفه» را بلافاصله از طریق بات تلگرام اطلاع می‌دهد.
